## Publish to the existing GitHub Pages website

1. Open the GitHub repository already serving **aaronspivak.com** (your `website` repository).
2. Upload the files in this folder to the **repository root**, replacing the existing `index.html` and any matching files. **Do not upload the ZIP file itself.**
3. Commit the changes to the branch currently selected in **Settings → Pages**. Preserve the existing GitHub Pages settings and working DNS entries at Namecheap.
4. Visit `https://aaronspivak.com/` and check that the new page appears. Check `https://aaronspivak.com/sitemap.xml` and `https://aaronspivak.com/robots.txt` too.
5. In [Google Search Console](https://search.google.com/search-console/welcome), verify the site and submit the sitemap. Request indexing of the home page, then add a link to this domain from your LinkedIn and conference profile(s) if you have access.
