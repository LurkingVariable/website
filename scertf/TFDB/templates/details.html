Details for {{ query }}

The Table below describes all of the matrices annotated to {{ query }} in this database. For each individual matrix, we provide several metrics related to the performance of that matrix in accurately representing the DNA binding specificity of the annotated transcription factor. The Fisher's p-value represents the probability that the recommended matrix identified {{query}}-bound promoters by random chance. If no experimental data exists for this particular TF, the field is labeled as "No Data". In addition to benchmarking against high-throughput experimental data, we also inform our recommendations based on matrix information content, length, and corroboration by experimental studies of individual of cis-regulatory sequences.

Each individual matrix can be downloaded as a position count matrix (PCM), position frequency matrix (PFM), or position weight matrix (PWM). Click on the appropriate button in the left column to download the desired matrix.

Also provided is a recommended cutoff to use when scanning a genome for regulatory sequences with the provided position weight matrix. An optimal cutoff was identified for each position weight matrix that provides the greatest discriminative power to distinguish between bound and unbound sequences in available ChIP experiments.
